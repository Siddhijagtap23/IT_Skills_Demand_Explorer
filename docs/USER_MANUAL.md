# 1. Introduction

This user manual explains how to use the IT Skills Demand Explorer application.

The application helps students and job seekers understand the most demanded technical skills in the IT industry, compare job roles, identify skill gaps, and create learning plans.

# 2. System Requirements

The following are required to use the application:

- A computer or laptop.
- A modern web browser such as Google Chrome.
- A stable internet connection.
- A registered user account.

# 3. Getting Started

1. Open the IT Skills Demand Explorer application in a web browser.
2. The home page will be displayed.
3. Register a new account if you are a new user.
4. Log in using your registered email and password.
5. After successful login, the dashboard will open.

# 4. User Registration

1. Open the registration page.
2. Enter your username.
3. Enter your email address.
4. Enter your password.
5. Submit the registration form.
6. After successful registration, log in to the application.

# 5. User Login and Logout

## Login

1. Open the login page.
2. Enter your registered email and password.
3. Click the Login button.
4. The system verifies the credentials.
5. After successful authentication, the user can access protected features.

## Logout

1. Click the Logout option.
2. The current session will be closed.
3. The user will be redirected to the login page.

# 6. Dashboard

The dashboard provides an overview of IT job market information.

Users can:

- View total job postings.
- Explore available job roles.
- Identify top demanded technical skills.
- View skill demand charts.
- Apply available filters.

# 7. Job Role Comparison

This feature allows users to compare two IT job roles.

Steps:

1. Open the Job Role Comparison page.
2. Select the first job role.
3. Select the second job role.
4. Click the Compare button.
5. View common skills and role-specific skill requirements.

# 8. Skill Demand Trends

This section displays how technical skill demand changes over time.

Users can:

- Select a technical skill.
- Select a time period.
- View skill demand trends.
- Understand changes in industry requirements.

# 9. Salary and Experience Insights

This section helps users explore salary and experience requirements.

Users can:

- View salary information.
- Explore minimum and maximum salary ranges.
- Compare salary insights across job roles.
- Understand experience requirements.

# 10. Skill Gap Analyzer

The Skill Gap Analyzer helps users understand their readiness for a selected job role.

Steps:

1. Open the Skill Gap Analyzer.
2. Select a target job role.
3. Select the technical skills already known.
4. Submit the information.
5. View the readiness score.
6. Review missing skills.
7. Check the recommended learning priority.

# 11. Learning Plans

Users can save and manage their learning plans.

Steps:

1. Open the Learning Plans page.
2. Create a new learning plan.
3. Select a target job role.
4. Save the plan.
5. View saved plans whenever required.
6. Delete a plan when it is no longer needed.

# 12. Admin Instructions

Administrators have additional permissions to manage application data.

Admin activities include:

- Uploading CSV job posting datasets.
- Viewing uploaded datasets.
- Managing job roles.
- Managing technical skills.
- Managing users.
- Monitoring dataset processing status.

# 13. CSV Upload Guidelines

Administrators should follow these guidelines:

- Upload CSV files only.
- Maximum file size is 20 MB.
- Include all required columns.
- Use valid job posting information.
- Avoid unnecessary duplicate records.

Required CSV columns:

`job_title, role, company, location, experience_min, experience_max, salary_min, salary_max, skills, posted_date`

# 14. Troubleshooting

| Problem | Possible Solution |
|---|---|
| Unable to log in | Check email and password |
| Dashboard not loading | Refresh the page and check internet connection |
| CSV upload failed | Check file format, size, and required columns |
| No analytics available | Check whether a dataset has been uploaded |
| Unable to save learning plan | Check login status and required fields |

# 15. Conclusion

IT Skills Demand Explorer provides a simple interface for exploring IT skill demand and understanding job market requirements.

This manual guides users and administrators through the main features of the application.
